# 漫画气泡、模型预览与客户端播放边界（2026-10-26）

## 回复渲染与输入边界

原 `ReplySurface.vue` 用纯文本插值，所以 `**粗体**`、列表等符号直接显示。改为 Markdown 解析后进行标签/属性白名单净化，只保留排版元素；图片、脚本、控件不进入 DOM，链接二次限制为 HTTP(S)。预览通过事件出口演示，真实气泡通过现有浏览器入口打开；不用 `v-html` 直接信任模型原文。Electron 的 [安全建议](https://github.com/electron/electron/blob/main/docs/tutorial/security.md) 也要求谨慎处理外部内容与 `openExternal`。

渲染只影响展示，不把 HTML 送回引擎、不改语音文本/记忆。真实浏览器用包含 `<script>`、远程图片和 `javascript:` 链接的样本验收：不执行脚本、不插入图片、移除危险 href，强调和列表仍正确显示。

## 复用渲染器，而不让预览接管桌宠

`UiScenePreview.vue` 复用 `Live2DCanvas` 的实际模型加载与渲染，增加 `preview` 参数：跳过首次 `fitWindowToModel`、跳过 Alpha 轮廓采样，使用预览容器自身的缩放；不会触发真实桌宠换装或改动共享 appearance 配置。只在勾选预览时挂载第二个画布，关闭/离开页卸载。尚未量化双画布 GPU/帧耗时，不能把“未改窗口大小”当成零成本；低负载场景可保持关闭。

预览复用主进程的纯布局函数。一次截图检查发现：`getModelRect()` 缓存的是 client 坐标，而调试台滚动后旧 client 坐标并未随之刷新，导致气泡与功能岛错位。增加局部模型矩形读取，按 `.scene-model` 容器偏移计算，避免依赖页面滚动位置。气泡高度从实际预览 DOM 测量；预览区域不足明确提示，不偷偷覆盖角色。真实模型、合法 placement 和截图均纳入实机检查，不能只检查模型已加载。

## 漫画形状与呼出菜单

曲线尖端在回复窗口内占据一段透明留白，正文宽度与尖端宽度分开计算；翻到模型左侧时尖端镜像。实际窗口仍受模型/工作区/其他卡片避让，尖端不会穿过模型。圆角、内边距、描边、说话高度可继续调整，不将漫画形状做成不可改的位图。

功能岛参数进入已有 `uiAppearance` 白名单归一化，本机跨窗口同步；按钮位置夹紧在对应视口，纵向间距至少容纳按钮。预览中初始就已打开的菜单暴露了旧 watcher 未立即初始化的问题，补上立即执行与动画版本检查，避免快速开/关的旧动画最终把新菜单隐藏。没有恢复常驻呼出按钮。

实测 62 px 按钮在当前 DPI 下 `getComputedStyle` 可能返回 61.9952 px。诊断允许小于 0.1 px 的数值误差，不能把小数取整误判成热更新失败。滚动条在空闲时透明、悬停/聚焦时显现，内容仍可以滚轮和键盘访问。

## 入口、工具与提示词必须一致

只删除“桌宠播放器”按钮不够：歌曲行点击仍会进入旧 `pick` 路径，Agent 的 `netease_play`/推荐工具也可能继续启动 mpv。因此同时将行点击路由到官方客户端，并在文本/语音入口禁用旧播放/控制/自动推荐/账号写工具。元数据查询保留，避免把“替换音频播放渠道”误写成“完全替换网易云开放平台”。

测试进一步发现，原 `disabled_tools` 主要控制 schema；关键词预路由和模型返回的禁用 tool_call 仍需执行侧拒绝。补齐这两处，增加“预路由暂停”和“模型强行调用禁用播放工具”测试，真实工具均不执行。音乐能力说明必须在每轮唯一 ContextEngine 入口重建消息后追加，单独追加到最初的 `messages` 会在工具轮丢失；测试覆盖最后一轮提示仍在。

短暂停/继续复用 `official_client` 的当前角色 ownership；未拥有的播放器不动，手动换曲则解除归属，Stop 如实说明仅暂停，返回状态不符不宣称完成。没有将通用 SMTC 或全局媒体键当成客户端功能缺失的兜底。

## 个性化能力的后续接入原则

当前候选随机选择只需要有效 ID，不需要新的账号 API；它是用户显式触发的候选选择，不是“网易云平台推荐”。喜欢/取消喜欢必须做成目标状态与写后核验，不能反复点击 toggle 猜结果。官方客户端搜索和收藏都还需要独立能力验证；固定本机当前歌曲投影不等于可以安全地执行任意客户端内部脚本。

网易 [公开 Skills](https://github.com/NetEase/skills) 展示了搜索、歌单和偏好推荐，但其依赖关系仍是 CLI/开放平台授权。本项目保留相关代码作为对照，不把它当作无需 API 的客户端能力保证。

验收口径、截图、907 项后端测试及后续任务见 [计划报告](../plan/ui-comic-and-client-only.md)。本轮保留现有 Runtime 和安全后端，不推进 G1。
