# 单曲线呈现层与客户端 UI 搜索复盘（2026-10-26）

## 极简文字与曲线为何分层

原漫画气泡的尾巴在自身窗口内，无法从文本区真正连到角色嘴部；扩大可点击文字窗口去覆盖整段连接线，会让透明区域挡住模型交互。保留原文字窗口，新增 `DialogueLineApp.vue` 的透明、不可聚焦、全窗口忽略鼠标呈现层；这个层无 Engine 连接，不接收选歌或账号操作。预加载仅增加固定的 `onDialogueLine` 呈现消息。

主进程在已有布局之后，用 `shared/dialogueLine.ts` 同一函数计算单条开放三次贝塞尔路径，朝角色侧点向外出发、终点水平接近文字。颜色/线宽/锚点在设置 schema 及主进程均限制范围；不接受调用方提供 SVG/HTML/任意路径。曲线没有填充、箭头或闭合 `Z`。角色隐藏、最小化、正文测量未就绪、旧 key 或空内容时隐藏；其包围区为后续结果卡留出避让空间。

正文沿用安全 Markdown，line 模式移除底色、边框、闭合尾巴及子元素背景，字形/排版/阴影独立设置。气泡旧设置仍保留；不是通过把气泡透明度设为 0 假装“无线框”。资源侧点标定区分 Hiyori/Hotaru，预览与真实窗口使用同一标定函数，可手动覆盖，未宣称自动跟踪嘴部。

## 客户端搜索：输入成功不等于搜索成功

最初仅输入关键词与 Enter，读到的是搜索建议，没有歌曲结果。检查实际页面发现 Enter 需要字符信息与输入状态提交时间；加入短输入提交等待和完整 Enter 事件，才能进入真实结果页。读取结果不依赖 CSS 哈希类名：页面要求 `page_pc_search_result` 的查询词匹配，单曲项要求 `cell_pc_common_songcard` 与 `s_ctype=song`，只投影 `s_cid`、标题、歌手三个公共字段。

综合页也包含播客/声音，ID 格式相似，必须按类型过滤，否则会把声音 ID 作为歌曲播放。当前限制可见 6 首；连续两次快照一致才交付。不把旧查询、未加载或无法识别页面当作“空结果成功”，也不读完整 DOM、完整 store、账号或遥测参数。

所有实际操作仍经 `NativeBackend.media_control(client_search)`；复用本机端口/进程 exe/固定页面核验，只能操作已确认的官方客户端。关键词是 CDP 输入参数，不插入执行脚本文本。生产适配器只使用固定表达式与固定 CDP 方法，未开放通用 JS 执行工具。

## 查询生命周期与生产接线

`NeteaseClientSearchTool` 复用旧工具名而替换日常注册实现，取消 ncm-cli 环境门槛；旧 API 类保留用于历史兼容测试。工厂延迟绑定当前角色/活动 Session 身份，搜索前后检查身份；适配器 gate 检查 epoch，旧排队请求不再执行，已返回的旧角色结果不入卡。结果广播对 song/playlist/source 都核对 generation，前端也拒收提供了旧角色身份的音乐结果。

首轮完整 Agent 验收受 Hiyori Flash 模型额度限制，未伪造工具结果卡绕过。为保证用户无需 LLM 也能使用确定的搜歌动作，新增 `/搜歌` 和输入框菜单入口，经认证 `media:search` 消息到同一个服务。请求和回复类型收在 `shared/engine-protocol.ts`；服务器核对身份、功能开关与代际，重复请求取消前一个任务，角色 quiesce/连接关闭也取消；前端用请求 ID 和角色/Session 丢弃旧回复。它不写聊天记忆，不触发 TTS，是正式的窄 UI 能力入口。

后来通过同一安全密钥分别最小调用，确认 Flash 403、Max 200；用户自行将 Hiyori 也切到 Max 后，两角色完整自然语言链路通过。因此报告保留历史中止，但最终验收不再标为 LLM 受阻。

## 验收没有互相冒充

单曲线 UI 样本仅本地显示；真实搜索和播放不 mock。结果卡实际点击原版 ID 36308916，等待客户端 ID/SMTC 状态再暂停，不根据 API 可播标志选 Remix。显式搜歌与自然语言 Agent 两种入口分开记录；候选原生页缓存使重复查询很快，不把暖缓存耗时当作全新外网检索保证。

窗口协调器单测验证曲线 ignore-mouse、不可伪装 results sender、单路径与隐藏清理；实机核对 `WS_EX_TRANSPARENT`、正文透明、样式热更新及双向角色清理。后端测试覆盖固定查询/稳定 ID、无 CLI 回退、取消、旧身份/代际、冷启动和不强制重启已有客户端。实测结束恢复原角色/偏好、测试曲目暂停；不自动恢复用户原曲以免造成新的播放副作用。

## 喜欢与平台推荐仍有明确门槛

可读到按 ID 关联的喜欢按钮，以及有隐藏副本的播放栏“喜欢/随机播放”控件。这证明可定位 UI，不证明持久账户状态已改变。当前没写红心，也没改变随机播放模式；未验证前不接到结果卡或 Agent。后续使用“目标状态 + 前置 ID 校验 + 写后 ID/状态读回”，避免快捷键/重复 toggle 误操作其他曲目或撤销刚完成的收藏。
