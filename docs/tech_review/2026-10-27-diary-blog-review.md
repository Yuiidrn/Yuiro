# 博客式日记与聊天坞调整复盘

本轮保留现有 Runtime、DiarySession、DiaryService、数据库和独立窗口，只替换日记表现层、补齐保存流程，并扩展聊天坞偏好。没有引入 Astro、视觉推理库或新的后台进程。

日记原先存在两套入口：调试台归档和独立记录窗口。归档现复用 `DiaryPanel`，嵌入记录窗口时通过 write 事件返回编辑；调试台入口则打开独立窗口。两者共用 token 配色，原生标题栏仅接受日记窗口自身发送的限定 skin/theme。

比美化更重要的保存问题是：尚未追加的输入不能遗漏、重连不能重置草稿、异步整理不能覆盖新文本。解决方式分别是追加 ACK 后保存、start 返回现有草稿、revision 判定失效；失败保留 pending，保存中门控阻止并发。原文保存增加单独协议事件并传空结构数据，明确跳过 LLM 解构。

录音转写、可选回应、WS 回调使用草稿/连接 epoch 和段落请求对应，防止换角后旧结果进入编辑区。默认关闭辅助回应，启用时也只调用独立日记通道，不将正文作为普通 Agent 指令。窗口内临时草稿与持久化恢复是不同能力，本轮未做磁盘自动草稿。

聊天坞继续用 VueUse localStorage 跨窗口同步；位置既有参数范围校验，也有 CSS 几何边界限制。上移扩大模型底部保留区，提供安全操作空间，但不把过度偏移包装成无代价功能。

实际截图只保留空编辑页及内存演示条目，不发布用户日记。真实临时草稿验证后撤回，不产生测试记录；摄像头未打开。测试、截图和剩余限制见[验收报告](../plan/dock-and-blog-diary.md)，未来视觉接入见[方案](../plan/vision-tab-evaluation.md)。
