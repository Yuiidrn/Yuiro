# 调试台 UI 自定义补齐

日期：2026-10-24。范围：独立回复、音乐结果/控制、联网来源以及既有轮廓/渐隐设置。保留现有 Runtime、播放器归属和独立窗口，不改角色配置。

- Goal / 场景：调试台调整新增面板外观立即生效，无需真实聊天/联网/音乐即可预览。
- 最小增量：复用旧宽度/透明度/偏移偏好；新增有边界的本机共享外观偏好、真实组件预览、分组重置；更正功能岛旧说明。
- 项目：回复侧边/字号/行距/高度/圆角；结果卡字号/高度/密度；来源独立尺寸与摘要/日期；独立窗口主题、模型留白、结果停留时长；保留播放器选择和暂停语义。
- 验收：类型检查、构建、布局/围栏回归；运行窗口热更新、尺寸边界、来源与音乐预览无副作用、重载持久化、双角色切换后共享偏好和旧动作拒收。
- 边界：空间避让仍优先，不能用个性化设置覆盖模型或移除角色/会话围栏。预览不会调用引擎，不播放歌曲、不打开链接、不污染真实回复。

## 已完成

调试台“UI”页新增“独立回复与结果面板”，使用回复、音乐/候选、联网来源三个分组；已有聊天坞、模型/窗口、渐隐、轮廓设置继续保留。旧宽度/透明度/偏移键未迁走或覆盖，原偏好继续生效。

| 分组 | 可调整项 |
|---|---|
| 共用 | 日间/夜间/跟随桌宠主题；与模型/其他面板留白 4–48 px |
| 回复 | 优先左右侧、宽度、高度、字号、行距、圆角、内边距、透明度、双向偏移 |
| 音乐/候选 | 宽高、字号、行距、圆角、内边距、透明度、偏移、优先侧、紧凑间距、播放器按钮纵排、可播说明、官方网页按钮、停留时长 |
| 来源 | 可选独立宽度/高度/字号，或继承结果卡；摘要 1–8 行、发布时间开关、独立停留时长 |
| 原有设置 | 窗口/模型大小、聊天坞、渐隐及轮廓参数；修正“常驻功能岛始终保留”的过期说明 |

新参数写入本机 `yuiro-detached-ui-v1`，Hiyori/Hotaru 共用显示偏好；角色的大脑、声音、人设、表演与数据隔离不变。参数从合法范围内选择，也可直接输入数值；每组单独恢复默认，不重置无关组。来源独立样式默认关闭，避免改变既有结果卡宽度。

## 预览与热更新

- 调试台内预览直接复用真实 `ReplySurface`、`ResultCard` 与同一套样式计算，不是另画一套静态图片。预览文字可编辑，不保存到聊天/记忆。
- 预览中的选歌、暂停/继续、来源与官方网页按钮只显示本地演示说明，不发送音乐请求、不打开链接、不调用 LLM/TTS/检索。
- 实际窗口通过同源偏好热更新，尺寸变化触发原有 ResizeObserver 与避让布局。优先侧只决定尝试顺序，不能强制覆盖模型；空间不足仍收起。
- 改停留时长会重新安排当前普通卡片；0 为手动收起。官方播放器存在当前归属时，候选时长不自动隐藏控制卡。不可播/试听/未知提示、播放器选择和暂停/继续不会被外观设置隐藏。
- “跟随桌宠主题”同时更新真实窗口与当前调试台预览，调试台自身的日夜主题保持独立。

## 实测与回归

证据：[live.json](ui-customization-artifacts/live.json)，脚本 `scripts/diag/ui_customization_acceptance.py`。使用受控显示样本、实际 Vue 控件及 Electron 窗口；角色切换经过真实引擎，不冒充真实聊天、联网或歌曲播放。

1. 实际数字输入框修改回复字号，独立回复同步更新；高度、圆角、夜间文字颜色一致。
2. 重载独立回复 renderer 后仍读取已保存偏好。
3. 音乐按钮纵排、官方网页按钮显隐在真实卡片和预览中生效；预览点击只显示本地说明。
4. 来源卡单独 340 px 宽、19 px 字号、180 px 最大高度、两行摘要/隐藏日期生效；关闭独立样式即时继承结果卡字号。
5. 同窗口主题跟随、当前卡片时长热更新、分组重置均通过。
6. 离开 UI 页后，在桌宠窗口改偏好，再返回 UI 页仍同步。为此修正了与组件挂载生命周期绑定的存储监听：新偏好在独立 effect scope、模块加载期初始化，不随设置组件卸载。
7. Hiyori→Hotaru→Hiyori 显示偏好一致，切换清理旧回复与卡片；没有 chat:user 或 media:* 请求。
8. 验收结束恢复了测试前的全部相关偏好及原角色，没有把测试字号或主题留给用户。

字体 computedStyle 更新实测在数毫秒量级，具体本轮记录见 live.json；仅为这个观察点，不作为整条渲染延迟保证。Windows 混合 DPI 下原生宽度可能向上取整 1 px，验收允许这一偏差，不把它当作热更新失败。

收尾补齐了调试台最小化后的重新呼出恢复，并实机验证 restore 成功。最终 Hiyori 在线、模型就绪、测试回复/卡片已清理：[final.json](ui-customization-artifacts/final.json)。新设置分组控件独立声明样式，不依赖父组件 scoped CSS，避免新增面板出现未套用主题的原生灰色按钮。

前端 `pnpm typecheck`、`pnpm build` 通过；`ui_appearance_test.cjs` 验证部分/非法偏好、范围、主题、继承、不同 gap 下不遮挡、计时器与官方控制卡保留；现有 `detached_frontend_test.cjs`、`contour_frontend_test.cjs`、`c0_frontend_test.cjs` 通过。本轮未改 Python 引擎代码，没有重复运行无关后端全量测试；上一轮后端 904 项通过的记录仍见官方客户端报告。

## 代码落点与限制

- `shell/src/shared/uiAppearance.ts`：默认值、白名单归一化与同源样式变量。
- `shell/src/renderer/src/composables/useUiAppearance.ts`：窗口级偏好、同步和分组重置。
- `shell/src/renderer/src/dev/components/DetachedUiSettings.vue`、`UiRange.vue`：设置、数值输入和安全预览。
- `shell/src/renderer/src/components/ReplySurface.vue`、`ResultCard.vue`：实际显示组件，调试台共用。
- `shell/src/renderer/src/App.vue`、`detached/DetachedApp.vue`：显示快照、来源宽度、当前卡片计时与跨窗热更新。
- `shell/src/main/detachedLayout.ts`：有界留白；保留模型、屏幕边缘和面板之间的避让规则。

调试台内预览演示外观，不模拟物理屏幕位置；左右微调、模型跟随和屏幕避让以真实桌面布局为准。新显示参数是本机共享，不新增角色专属外观卡或配置导入/导出功能。未恢复常驻功能岛，没有改变轮廓命中、点击穿透、播放器协议或 Runtime。
