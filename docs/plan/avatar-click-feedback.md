# 桌宠单击反馈动作池

日期：2026-11-01。目标：用户单击角色轮廓，立即从自己配置的动作池随机播放一次；在调试台可增删选择，拖动和UI操作不误触。

## 已实现行为

- 调试台“外观”页新增“单击反馈动作池”，支持启用、从当前模型动作下拉添加、逐项移除、推荐动作、清空。即时保存生效，无需调用大模型。
- 按角色ID及模型路径分别保存，换角或换模型不继承不匹配动作。未知/已删除动作过滤掉；显式清空保持为空，不偷偷恢复默认。
- 初次默认推荐招呼、庆祝、思考、点头、环顾槽位，以及短时待机动作；Hiyori无语义文件名使用现有短待机候选，Hotaru使用已推断语义。推荐是资源索引规则，不冒充全部动作已人工审定；用户可改选。
- 只接受左键、轮廓内短按（≤600ms、移动≤5px）；按钮/输入/聊天坞不触发。移动超过5px才启动原生拖动，拖动释放、右键、失焦不触发单击。保留现有Alpha命中及透明区域穿透。
- 用户单击以USER优先级4进入现有表演入口，动作期间注视和待机让位，结束后沿用基础表情恢复与SDK完成回执。多候选时避免连续重复，单候选仍可用；600ms触发冷却防止瞬间重复启动。

## 实现边界

`clickFeedback.ts`负责推荐/校验/短按判定，`useAvatarClickPref.ts`负责同源持久化与角色/模型隔离，`AvatarClickCard.vue`负责配置。`usePetDrag.ts`统一处理短按与拖动的分界，App仅把有效单击交给Live2DCanvas。没有添加另一套动作播放器或LLM工具。
