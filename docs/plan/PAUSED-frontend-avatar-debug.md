## 一、Avatar 调试面板（最该先做的）

### 要解决的实际问题

想试"眉毛下压 0.6 是什么样"，现在只能：改 JSON → 重启引擎 → 肉眼比对。
而且 `Alt+M` 只覆盖 `TapBody` 一组 —— **换模型后的 `mtn_*` / `special_*` 完全看不到**；
也没有任何地方能看**当前参数的实际值**。

### 方案（照 `Alt+G` 表演库的模式做，成本低）

| 能力 | 数据来源 | 备注 |
|---|---|---|
| 列出现有表情 | `model3.json` 的 `Expressions` | **与模型解耦**，别硬编码 |
| 列出现有动作组 | `model3.json` 的 `Motions` | 同理 |
| **参数滑条** | `cdi3.json` 的 `Parameters` | 按分组折叠：头部/眼睛/眉毛/嘴/身体/手/头发 |
| 显示当前参数值 | Live2D 内部 model 对象 | 实时 |
| **一键导出 exp3.json** | 当前滑条值 | ★ 关键：把"调参"与"产出资源"连起来 |

> **最后一格是关键** —— 在面板上拖着看效果，满意了导出成新表情，
> **全程不需要 Cubism Editor**（moc3 不可手改，但 exp3/motion3 都是纯 JSON）。

### 已确认的技术事实（S44 调研，直接可用）

| 资源 | 能否手改 | 说明 |
|---|---|---|
| `*.moc3` | ❌ | 编译产物，需 Cubism Editor |
| `exp3.json` | ✅ | 表情＝给若干参数设值，**0.2KB 级别** |
| `motion3.json` | ✅ | 动作曲线（关键帧分段），可用脚本生成 |
| `model3.json` | ✅ | 动作组 / 表情列表 / 参数组 / HitAreas |
| `physics3.json` | ✅ | 头发、裙子摆动 |
| `cdi3.json` | ✅ | 参数元数据（**含中文名**） |

**现成模型资产**（`shell/src/renderer/public/live2d/`）：

| 模型 | 参数 | 表情 | 动作 | 备注 |
|---|---|---|---|---|
| 肥牛（当前） | 77 | 6 有效 | **13（最多）** | `expression1` 是空定义（无效果） |
| mao_pro | **128（最多）** | **8** | 7（含 3 个 `special_*`，33–47KB） | 参数最丰富，值得试一次 |
| shizuku | 45 | **0** | 4 | 最精简，无表情组 |

**已修（S44）**：`[persona.expression_map]` 此前**除 happy 外全部错位**（读出 `cdi3.json`
的中文名即知：`expression2=开心 / 3=生气 / 4=难过 / 5=惊讶 / 6=害羞 / 7=俏皮`，
而原配置把 sad 配成生气、angry 配成害羞…）。现为 `happy=2 / sad=4 / angry=3 / excited=5`，
`bored` 与 `thinking` **留空回落**（模型确无此二表情）。
