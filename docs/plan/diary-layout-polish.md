# 日记轻柔布局调整（2026-10-29）

参考[Bear](https://bear.app/)的内容优先和按需功能呈现、[Day One](https://dayoneapp.com/)的专注记录布局，仅借鉴布局原则，未引入素材或框架。

右上角改为统一分段导航、连接状态小点和图标设置按钮；保留tooltip/可访问名称。正文最大宽度由720扩至920，随窗口留出弹性边距；移除英文小标题和重复引导文字，快捷键与保存说明收进设置。输入区随窗口高度适配。侧栏改为圆角轻面板，增加200ms淡入滑入，回应轻淡入；系统减弱动态效果设置下禁用动效。两套角色配色仍取现有tokens。

本轮为UI局部修改，不改变触发、保存和记忆逻辑。类型检查与构建验证；未进行新一轮双角色真实桌面截图验收。
