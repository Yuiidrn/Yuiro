# Agent 能力测试矩阵（增量调试用）

> **用途**：这是**能力验收台**，不是 Sprint 计划。
> 每一行 = 一个可独立复现的场景 + 明确的通过判据 + 当前真实状态。
> 后续增量开发（联网检索、读项目、思考反馈…）都从这张表的 ⛔/🟡 行出发。
>
> 状态图例：✅ 已验证可用 · 🟡 有条件（依赖外部/未充分验证） · ⛔ 缺能力 · 🔧 需先改配置
> 最近核对：2026-09-14（S38 之后）

## 0. 前置：两件事决定"能不能测"

| # | 事项 | 现状 | 动作 |
|---|---|---|---|
| 🔧 | **`[systemd].file_roots = ["."]`** | 文件工具**只能碰 engine 目录** | 要测真实目录，先加路径：<br>`file_roots = [".", "D:/Project/Yuii/desktop-pet/test", "~/Downloads", "~/Desktop"]` |

| # | 场景 | 怎么说 | 期望 / 判据 | 现状 |
|---|---|---|---|---|
| A1 | 列目录 | "看看 D:\test 里有什么" | 调 `file_list`，按大小列出文件 + 子目录；**不重复调用** | ✅ S38 验收通过 |
| A2 | 读单文件 | "读一下 xxx.txt" | 调 `file_read`；内容进上下文；之后能追问细节 | ✅ 有实现 + 测试 |
| A3 | 写/建文件 | "在 test 下建 notes.txt，写…" | `file_create` → 文件存在；返回 `txn_id` | ✅ |
| A4 | 覆盖写 | "把 notes.txt 改成…" | `file_write`；**回滚能还原原内容** | ✅ S33 测试 |
| A5 | 批量移动 | "把这些图片都移到 图片/ 目录" | `file_move(paths=[…], dest="…/图片")` **一次调用一个事务**；空 dest 目录自动创建 | ✅ S38 验收通过 |
| A6 | 删除 + 撤销 | "删掉 a.txt" → "恢复刚才的操作" | `file_delete` → `transaction_rollback` → 内容回来 | ✅ S33 测试 |
